# "sound ^= regex:file": the first line whose regex matches a message plays
# its file (from sound_file_path). Lines in capitals match the game's own
# sound cues rather than messages. "music ^= branch:file": a branch's track,
# by its abbreviation, or "menu"; a branch with no track keeps the one
# playing. A pack unzipped to /data/crawl/sound-pack/ replaces these sound
# effects but keeps this music where it names no track itself.
